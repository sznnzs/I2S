WebShop accepts only search[query] and click[visible text] actions. On a search page, replace <your query> with your own concise query. On other pages, copy a currently visible click target exactly. Opening a currently visible product candidate from search results is a reversible inspection step, not a purchase commitment. Do not request help solely because its attributes require product-page inspection; when the exact candidate click target is visible and no visible fact contradicts the current request, open it and verify on the product page. Before buying, click every requested product option; seeing an option on the page does not select it. In text_rich observations, only [clicked button] marks a selected option; plain [button] marks an unselected option. Immediately before buying, inspect the current observation for every value requested in the task. If any requested value is still shown as plain [button], click that value first; click[buy now] is not yet allowed. Never infer selection merely from availability or earlier reasoning. If you open Description, Features, or Reviews, use click[< prev] to return to the product page. Purchasing is performed only with click[buy now].
